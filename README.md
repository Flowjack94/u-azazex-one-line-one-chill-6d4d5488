## Entry

One horror sentence, one breath, under 200 characters. A wedding photo —
the happiest day, the most familiar artifact — with a headcount that does
not add up, and the extra guest is standing behind you wearing your face.

## Run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (one line of text, nothing else).
